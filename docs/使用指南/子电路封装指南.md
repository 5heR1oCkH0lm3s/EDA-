# 子电路封装与复用

子电路保存完整的内部元件和连线，可以有多个输入、多个输出，也可以包含其他子电路。原有“真值表逻辑门”仍用于定义双输入、单输出逻辑。

## 封装自己的电路

1. 先画好并仿真验证电路；用开关作为外部输入、指示灯作为外部输出。
2. 停止仿真，用选择工具框选完整电路，包含接口开关、指示灯和内部逻辑门。选区不能有跨到外部的连线。
3. 点击“工程 → 将选中电路封装为元件...”，或左侧“子电路元件 → ＋ 封装选中电路...”。
4. 填写元件名称和端口名称；多个名称用逗号分隔，端口顺序按界面列出的 U 编号排序。
5. 确认后，原电路保留，定义加入左侧子电路元件库；在画布空白处点击放置。
6. 新方块左侧是输入、右侧是输出，按名称连线，再按 F5 验证。多个实例的开关状态和输出分别计算。

半加器原图 `examples/half_adder/half_adder.eda` 中，输入 U1/U2 命名为 `A,B`，输出 U5/U6 命名为 `S,C`。封装后可以像逻辑门一样放置、连线、复制、撤销和保存。

## 跨工程使用

“工程 → 导出子电路元件...”生成 `.edasub` 文件；在另一个工程通过“工程 → 导入子电路元件...”加入元件库。导入不替换当前画布，同名定义会提示冲突，请在封装时使用不同名称。

普通 `.eda` 保存画布和整个元件库，未放置的定义也保留；每个实例携带完整定义，重新打开不依赖外部文件。修改原图不会自动修改已封装定义，需要用新名称重新封装。

选中一个方块，使用“工程 → 查看选中子电路内部...”查看内部结构；此窗口只读，支持滚轮缩放、中键平移。

## 展示用示例

| 文件 | 用途 |
|---|---|
| `examples/subcircuits/half_adder.edasub` | 可导入的半加器，两输入 A/B、两输出 S/C |
| `examples/subcircuits/full_adder.eda` | 两个半加器方块和一个或门组成全加器 |
| `examples/subcircuits/full_adder.edasub` | 再封装的全加器，三输入 A/B/Cin、两输出 S/Cout |
| `examples/subcircuits/nested_full_adder.eda` | 一个全加器方块包含两层内部结构 |

打开 `.eda`，按 F5，依次切换左侧三个开关。全加器应满足 `S = A XOR B XOR Cin`，`Cout = AB OR ACin OR BCin`。例如三个输入为 1 时，S/Cout 都为 1。

## 当前边界

- 工程编辑限制约 9 MiB；重复嵌套较多时会提示减少实例。保存会验证重新读取，失败时保留已有文件。
- 每个子电路支持 1～16 个输入、1～16 个输出，最多嵌套 8 层；全部接口开关和指示灯都必须命名。
- 端口名称不为空且不重复，最多 24 字；子电路名称最多 80 字；每个工程最多 256 个库定义。
- 未连接的输入按 0 计算。当前支持组合逻辑，连接形成反馈环会被拒绝。
- 导出 KiCad 网表或原理图时自动展开为内部逻辑门与实际网络；不会把整个方块当作一个虚构芯片。展开后的内部元件位置可能重叠，应在 KiCad 整理布局。
- `.edasub` 从工程菜单导入，不能作为普通电路直接打开。

## 开发验证

`build.bat` 编译并运行基础逻辑和子电路测试。额外画布回归：构建 `test_canvas` 后运行 `MyEDA/build/Debug/test_canvas.exe`。

子电路实现入口：`src/core/Subcircuit.h`（接口验证、选区封装、层次展开），`src/sim/Simulation.h`（按输出引脚递归求值），`src/file/CircuitFile.h`（定义和工程存储）。目录均相对于 `MyEDA/`。

时序元件合并说明：支持顶层 D 触发器和时钟源，每 500ms 自动步进；D 触发器在上升沿采样。子电路封装目前用于组合逻辑，包含时钟或触发器的选区会提示暂不支持。
