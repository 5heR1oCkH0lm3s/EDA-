# 新人上手指南

本文所有命令均在 **PowerShell** 中运行。Git 命令也可以在 Git Bash 中执行，但不要混用两个终端的路径和续行语法。

## 一、首次准备

1. 安装 Git，确认 `git --version` 能输出版本。
2. 在 Visual Studio Installer 中安装 **Visual Studio 2022 → 使用 C++ 的桌面开发**，包含 MSVC x64 工具、Windows SDK 和 C++ CMake 工具。
3. 准备 wxWidgets 3.2（本项目使用过 3.2.2.1）的 **x64 静态库，包含 Debug 库**。检查 `lib\vc_x64_lib` 下有 `wxmsw32ud_core.lib` 和 `wxbase32ud.lib`。

脚本优先使用 PATH 中的 CMake，也会查找 Visual Studio 自带 CMake，无需手动修改 PATH。仅能搜到 Visual Studio Installer 不代表 C++ 工具已经安装。

第一次获取项目（进入你准备放项目的父目录后执行）：

```powershell
git clone https://github.com/Pengyang-uestc/EDA-.git
Set-Location .\EDA-
```

已有项目不用再次克隆。例如本机仓库在 `E:\EDA task\EDA-repo`，进入它：

```powershell
Set-Location 'E:\EDA task\EDA-repo'
```

下文均以仓库根目录（含 `README.md` 和 `build.bat`）为执行目录。

## 二、首次编译

双击 `build.bat`，或在 PowerShell 中执行：

```powershell
.\build.bat
```

脚本查找 wxWidgets 的顺序为：`-Wx` 参数、`WXWIN` 环境变量、课程资料的几个常见目录。找不到时手动指定实际路径：

```powershell
.\build.bat -Wx 'E:\你的工具目录\wxWidgets-3.2.2.1'
```

想让以后双击也能找到：在 Windows“编辑账户的环境变量”中新建用户变量 `WXWIN`，值填 wxWidgets 根目录（不是 `lib` 子目录），然后重新打开终端；若从资源管理器双击仍未生效，注销并重新登录 Windows。

脚本会配置工程、编译程序、编译测试、运行测试。看到 `ALL PASS` 且最后显示“编译和测试全部通过”才是成功。任一步失败会返回非零退出码，并停止后续步骤。

`-Clean` 使用 CMake 的 `--clean-first` 重新编译，不删除整个 build 文件夹，也不重置 CMake 缓存；平时无需使用。

## 三、运行与示例

双击 `MyEDA\build\Debug\MyEDA.exe`。首次编译前此文件不存在。

程序中选择“文件 → 打开”，打开 `examples\half_adder\half_adder.eda`，按 F5 仿真，点击开关观察灯；按 F6 停止仿真后再编辑。

也可以从仓库根目录直接带文件启动：

```powershell
.\MyEDA\build\Debug\MyEDA.exe .\examples\half_adder\half_adder.eda
```

## 四、日常选哪个入口

| 场景 | 操作 |
|---|---|
| 拉取当前分支的远程更新并运行 | 先保存电路、关闭 MyEDA，再双击 `update-and-run.bat` |
| 修改了代码，想验证本地效果 | 关闭 MyEDA，双击 `build.bat`，通过后打开 exe |
| 没有更新，也没有修改源码 | 直接打开 exe，无需重新编译 |

更新入口自动执行 `git pull --ff-only`、编译、测试和启动；只更新**当前分支的上游**，不会自动切换 main，也不会把 main 合入功能分支。存在未提交修改（包括未跟踪文件）、缺少上游、分支分叉或网络错误时会停止。已经拉取但编译失败时，源码会保留在更新后的版本，程序不会启动。

需要手动指定依赖时：

```powershell
.\update-and-run.bat -Wx 'E:\你的工具目录\wxWidgets-3.2.2.1'
```

关于修改代码、首次推送与合并，请阅读《四人协作指南》（`docs/开发协作/四人协作指南.md`）。

## 五、常见问题

| 提示或现象 | 处理 |
|---|---|
| 找不到 Git | 安装 Git，并重新打开终端 |
| 找不到 CMake / Visual Studio 2022 | 用 Visual Studio Installer 补齐 C++ 工作负载和 CMake 工具 |
| 找不到 wxWidgets，或链接缺少库 | 检查 `WXWIN` / `-Wx`，确认是 x64 静态库且有 Debug 库 |
| 存在本地修改 | 先用 `git status` 检查；自己代码尚未完成时用 `build.bat` 验证，不强制覆盖 |
| 没有远程跟踪分支 / 无法快进 | 按《四人协作指南》处理，不能靠反复点击更新解决 |
| 无法覆盖 MyEDA.exe | 保存电路并关闭正在运行的 MyEDA，再编译 |
| 编译或测试失败 | 保留第一条错误和 FAIL 输出给模块负责人；不要只看最后一行 |
| 拉取网络失败 | 检查 GitHub 连接后重试；无需删除仓库重新下载 |
| 教程合集检查失败 | 修改分篇文档后重新运行 `python .\tools\merge_docs.py` |
