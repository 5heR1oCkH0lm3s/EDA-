## 二、答辩 PPT 大纲(约 15 页,20 分钟汇报)

### 第 1 页:封面
- 项目名称:电路原理图编辑器
- 课程:工业软件创新训练 I
- 小组成员:＿＿＿、＿＿＿、＿＿＿、＿＿＿
- 日期:2026-09-17

### 第 2 页:项目概览(做了什么)
- 用 C++17 + wxWidgets 实现的**电路原理图编辑器**
- 支持画电路(6 种门+开关+灯+自定义)、仿真(逻辑+时序)、存档(.eda)、导出网表(KiCad 格式)
- 代码 3254 行,67 项单元测试,25 次提交

### 第 3 页:系统架构(分层设计)
- **core/** 数据模型 → **editor/** 绘图交互 → **sim/** 仿真引擎
- **file/** 存档与网表 ← **ui/** 界面
- 核心原则:**数据是核心,界面只是把数据画出来**

### 第 4-5 页:功能演示(截图,每页 1~2 个)
- 三栏布局主界面(元件库树+绘图区+属性表)
- 画电路+仿真(导线变色,LED 亮灭)
- 半加器真值表验证
- 存档/打开/网表导出/导入
- KiCad 里打开我们导出的原理图/PCB

### 第 6-7 页:关键设计决策(每页 1 个技术点)
- 快照式撤销(JSON 压栈,不用写反操作)
- 并查集网络归并(扇出正确处理)
- 双缓冲绘制(防闪烁)
- 网格吸附(SnapGrid 对齐 10px)
- 提示回调(画布不依赖主窗口,依赖倒置)

### 第 8-9 页:测试
- 单元测试 67 项(逻辑/存档/网表/交互),全部 PASS
- 三层测试:单元测试 → GUI 自动化 → 端到端验收
- KiCad 导入 0 错误

### 第 10 页:遇到的困难与解决
- 编码问题(UTF-8 vs GBK)→ `/source-charset:utf-8`
- 或门弧线方向 → 改用折线近似
- 删除"静默失败" → 加状态栏提示回调
- 网表扇出错误 → 并查集归并

### 第 11 页:不足与展望
- 不支持时序元件动画(已有 D 触发器和时钟源,但无动画波形)
- 元件固定 2 输入,不支持 3+ 输入门
- 无打印/PDF 导出

### 第 12 页:总结
- 六个任务全部完成,45 次提交,67 项测试,2514 行核心代码
- 分层架构 + 注册表模式 + 快照撤销 + 迭代仿真
- 感谢 + Q&A
