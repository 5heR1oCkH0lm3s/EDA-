## 维护规则

修改分类目录里的分篇文档后，在根目录运行 `python tools/merge_docs.py`，用 `python tools/merge_docs.py --check` 检查同步；不要直接编辑合集。文档中的测试记录和截图需按实际版本复核。

本次目录迁移没有删除学习资料或样例，也没有移动 `MyEDA/src`、`MyEDA/test` 和 `MyEDA/build`。旧文档位置已分类迁移；源文档和脚本中的引用一并更新。

展示前请按 [阶段展示检查清单](课程资料/阶段展示检查清单.md) 练习完整流程。

## 子电路封装

支持把完整电路封装为多输入、多输出元件，并通过 `.edasub` 跨工程复用；演示工程见 `examples/subcircuits/`（从仓库根目录查找）。操作见[子电路封装指南](使用指南/子电路封装指南.md)。
