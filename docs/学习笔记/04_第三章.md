# 第三章 时序逻辑电路

## 3.1 为什么需要"有记忆"的电路

前两章讲的组合逻辑有一个致命限制：**它算完就忘**。

想想你需要什么：
- 要存一个数字？组合电路存不了。
- 要数数（计数器）？组合电路数不了。
- 要保存"现在是第几步"？组合电路做不到。

**时序逻辑电路**就是为了解决这些问题。它的核心特征（PPT 第 63 页）：

> **某一时刻的输出，不仅取决于当前输入，还取决于电路过去的状态。**

因为要"记住过去"，所以电路里必须有**存储单元**——而存储单元的基本组成就是**触发器**。

---

## 3.2 触发器：一个能"记住"的开关

组合电路的输出像水流过水管——水停了，输出就停了。触发器不一样：给它一个脉冲，它就"记住"这个状态，即使脉冲走了，状态还在那。

> 生活类比：普通开关拨一下动一下，松手就回去。触发器像那种"拨一下卡住"的开关——拨上去就停在上面，拨下去就停在下边，不会自己弹回来。

触发器的关键特性：
- 有**两种稳定状态**：0 态或 1 态。
- 任一时刻只处于一种状态。
- 接到触发脉冲才翻转。

---

## 3.3 基本 RS 触发器：最简单的记忆

### 3.3.1 电路结构

两个与非门交叉相连，互相"喂"对方的输入：

- 两个输入端：S（置位 Set）和 R（复位 Reset）
- 两个输出端：Q 和 非Q（Q 的反）

> 关键是**反馈**：第一个门的输出接到第二个门的输入，第二个门的输出又回到第一个门。这个"互锁"就是它"记住"的秘诀。

### 3.3.2 四种工作模式

理解触发器的关键，就是搞懂 S 和 R 的四种组合各发生什么。

---

**模式 1：置 1（S=0, R=1）**

S=0 时，和 S 相连的那个与非门，不管另一个输入是什么，输出强制为 1 → Q=1。
Q=1 又通过反馈影响到另一个门 → 非Q=0。

结果：触发器进入 **1 态**。

---

**模式 2：置 0（S=1, R=0）**

R=0 时同理 → Q=0，非Q=1。

结果：触发器进入 **0 态**。

---

**模式 3：保持（S=1, R=1）**

两个输入都是 1，两个与非门都只看对方的反馈输出。

- 如果原来 Q=1，它会一直维持在 1（因为两个门都收到 1，保持原状）。
- 如果原来 Q=0，它会一直维持在 0。

**这就是"记忆"的实现**：一旦置好状态，把 S 和 R 都放回 1，状态就锁住了，不会变。

---

**模式 4：禁止（S=0, R=0）—— 绝对不能出现！**

两个与非门的输出都强制为 1：Q=1 且 非Q=1。

这违反了 Q 和 非Q 应该相反的基本原则，而且一旦 S 和 R 同时回到 1，两个门都争抢，最终状态**不可预测**——可能 0 也可能 1，取决于哪个门翻转得更快。

所以**约束条件是：S + R = 1**（S 和 R 不能同时为 0）。

---

### 3.3.3 状态表总结

| S | R | Q(n+1) | 功能 |
|---|---|--------|------|
| 1 | 1 | Q(n) | 保持（记住原来的值） |
| 0 | 1 | 1 | 置 1 |
| 1 | 0 | 0 | 置 0 |
| 0 | 0 | 不定 | 禁止！ |

（Q(n) 表示当前状态，Q(n+1) 表示下一个状态。）

---

## 3.4 同步 RS 触发器：加了"时钟"的记忆

基本 RS 触发器有个问题：**S 和 R 一变化，输出立刻跟着变**，没有统一的"什么时候该变"的规则。

**同步 RS 触发器**（也叫 RS 锁存器）加了一个**时钟信号 CP**（Clock Pulse）来解决这个问题。

### 3.4.1 工作原理

在 S、R 到基本 RS 触发器之间，各加了两个与门，时钟 CP 控制这两个与门的开关。

- **CP = 0 时**：两个与门关闭，S 和 R 的值传不过去，触发器**保持原态**，不管 S 和 R 怎么变。
- **CP = 1 时**：两个与门打开，S 和 R 的值传进去，触发器**正常响应**。

> 形象说：CP 就像一扇大门。门关着（CP=0），门外怎么喊门里都听不见；门开了（CP=1），门里的状态才会改变。

### 3.4.2 优缺点

**优点**：有了统一的时钟控制，多个触发器可以在同一个时刻更新状态。

**缺点——"空翻"现象**：
当 CP=1 持续一段时间时，如果 S 或 R 在这段时间内多次变化，触发器的状态就会跟着翻来翻去，可能翻不止一次。这会造成逻辑混乱。

> 这就是为什么我们需要更好的触发器——边沿触发的触发器。

---

## 3.5 D 触发器：最实用的触发器

同步 RS 触发器有约束条件（S 和 R 不能同时为 0），还可能有空翻问题。**D 触发器**用一个巧妙的办法把这些问题都解决了。

### 3.5.1 怎么从 RS 变 D

RS 的约束条件是 R 和 S 不能同时为 1（高电平有效版本）。解决办法：把 R 和 S 限制成**只能是一个变量的两种状态**——

- S = D（输入数据）
- R = 非D（输入的相反）

这样 S 和 R 永远一个 0 一个 1，不可能同时为 0 或同时为 1，约束条件自动满足！

### 3.5.2 D 触发器怎么工作

| CP | D | Q(n+1) |
|---|---|--------|
| 0 | × | Q(n)（保持） |
| 1 | 0 | 0 |
| 1 | 1 | 1 |

**核心特性**：CP=1 时，Q 直接等于 D。CP 由 1 变 0 时，D 的值被"锁住"在 Q 端。

> 所以它又叫"锁存器"——在时钟的高电平期间把输入"锁存"住。

### 3.5.3 为什么 D 触发器最重要

1. **没有约束条件**——输入随便给，不会出错。
2. **行为简单直观**——时钟一到，输出等于输入。
3. **是实际工程里用得最多的触发器**。
4. **FPGA 内部全是 D 触发器**——你在 Verilog 里写的 `always @(posedge clk) q <= d` 就是 D 触发器。

---

## 3.6 寄存器：多个触发器并排就成"字"

一个触发器只能存 1 位（0 或 1）。把 n 个 D 触发器并排放，加上同一个时钟，就能存 n 位数据。

> 这就是**寄存器**。PPT 第 80 页："一个 D 触发器组成 1 位的数码寄存器。"

**8 位寄存器** = 8 个 D 触发器并排，就能存一个字节的数据。
**32 位寄存器** = 32 个 D 触发器并排，就是 CPU 里的通用寄存器。

**计算机为什么叫"计算机"**？因为它里面有大量的"寄存器"——专门存数据的小盒子。而这些盒子的基本单元，就是你刚学的 D 触发器。

---

## 3.7 从触发器到计数器（拓展理解）

虽然 PPT 没详细展开，但你想一想触发器的应用：

- 把 D 触发器的输出反馈到输入，每来一个时钟就翻转一次。
- 第一个触发器每 2 个时钟翻转一次（存 1 位）。
- 第二个触发器接到第一个的输出，每 4 个时钟翻转一次。
- 以此类推……

这就构成了一个**二进制计数器**：00、01、10、11、100、101……

FPGA 里的 `always @(posedge clk) count <= count + 1` 背后，就是一堆这样的触发器在翻转。

---

## 3.8 第三章小结：你应该会做的事

1. 区分组合电路（无记忆）和时序电路（有记忆）。
2. 说清触发器为什么能"记住"——靠反馈互锁。
3. 掌握基本 RS 触发器的四种状态（置 1、置 0、保持、禁止）。
4. 理解同步触发器时钟 CP 的作用和"空翻"问题。
5. 掌握 D 触发器的工作原理：CP=1 时 Q=D。
6. 理解寄存器 = 多个 D 触发器并排，能存多位数据。
7. 知道 FPGA 里的时序逻辑代码背后就是这些触发器。

```
逻辑代数的三种运算（与、或、非）
         ↓
     门电路（与门、或门、非门、与非门、异或门...）
         ↓ 组合
    ┌────────────────┐
    │  组合逻辑电路   │  ← 没有记忆，算完就忘
    │  加法器、MUX、  │
    │  译码器、编码器 │
    └───────┬────────┘
            ↓ 加触发器
    ┌────────────────┐
    │  时序逻辑电路   │  ← 有记忆，能存数据、能计数
    │  寄存器、       │
    │  计数器、状态机 │
    └────────────────┘
```

**你学 FPGA 写代码时，其实就是在描述这张图里的东西：**
- 写组合逻辑 = 在描述门电路的连接。
- 写时序逻辑 = 在描述触发器怎么存数据、怎么在时钟边沿更新。

把这三章搞懂了，你的 Verilog/VHDL 代码就从"凭感觉敲"变成了"心里有图"。
